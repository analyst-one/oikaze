    get

    @function get($token) { ... }

    Description

    Retrieves a value from a resolved token.

    By default, this function retrieves the value associated with the token as a CSS property value (var(--token, fallback)). If the token is prefixed with a '$', it retrieves the value associated with the token.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $token

    The token to resolve and retrieve the value for.

    		String— none

    Returns

    Any type —

    The value associated with the resolved token.

    Example

    .test {
  color: tokens.get('color.primary');
  opacity: tokens.get('$opacity.20');
  padding: tokens.get('size.small');
  border-color: tokens.get('dark:color.neutral');
}
    .test {
  color: var(--color-primary, #93b733);
  opacity: 0.2;
  padding: var(--size-small, 0.5);
  border-color: var(--color-neutral, #fefefe);
}

    percentage

    @function percentage($token) { ... }

    Description

    Converts a given token value to a percentage unit.

    By default, this function retrieves the value associated with the token as a CSS property value (calc(var(--token--em, fallback) * 100%)). If the token is prefixed with a '$', it retrieves the value associated with the token (XXX%).

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $token

    The value to be converted.

    		String— none

    Returns

    Any type —

    The converted value in percentage units.

    Example

    .test {
  opacity: tokens.percentage('opacity.50');
  --text-opacity: #{tokens.percentage("$opacity.20")};
}
    .test {
  opacity: calc(var(--opacity-50--em, 0.5) * 100%);
  --text-opacity: 20%;
}

    alpha

    @function alpha($token, $alpha: 1) { ... }

    Description

    Applies an alpha (opacity) value to a color token.

    By default, this function retrieves the value associated with the token as a CSS property value (color-mix(in srgb, var(--color-primary, fallback) alpha, transparent)). If the token is prefixed with a '$', it retrieves the value associated with the token (rgba(X, Y, Z, alpha)).

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $token

    The color token to resolve.

    		String— none
    $alpha

    The alpha value as a number (0-1), percentage, or quoted string.

    		Number or String1

    Returns

    Color —

    The color with the specified alpha applied.

    Example

    .test {
  color: tokens.alpha('color.primary', 0.5);
  background-color: tokens.alpha('$color.neutral', 'opacity.50');
}
    .test {
  color: color-mix(in srgb, var(--color-primary, #93b733) 50%, transparent);
  background-color: rgba(254, 254, 254, calc(var(--opacity-50--em, 0.5) * 100%));
}

    Throws

    • Oikaze error: alpha() only works with colors

    • Oikaze error: alpha() only accepts numbers or tokens for alpha value

    @mixin css-definitions($set) { ... }

    Description

    Outputs specified tokens CSS property definitions.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $set

    The name of the token set to use. If null, defaults to the current set.

    		String or Null— none

    Example

    :root {
  @include tokens.css-definitions();
}
.dark {
  @include tokens.css-definitions('dark');
}
    :root {
  --color-primary: #93b733;
  --color-neutral: #fefefe;
  --size-small: 0.5;
  --size-small--em: 0.5;
  --opacity-50: 50%;
  --opacity-50--em: 0.5;
}
.dark {
  --color-primary: #93b733;
  --color-neutral: #fefefe;
  --size-small: 0.5;
  --size-small--em: 0.5;
  --opacity-50: 50%;
  --opacity-50--em: 0.5;
}

    Output

    {CSS} CSS custom property definitions for all tokens in the specified set.
